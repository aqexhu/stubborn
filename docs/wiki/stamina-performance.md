# Stubborn Stamina Performance Data

The **Stubborn Stamina** series is engineered for long-duration backup and flexible battery compatibility.

## Typical Performance

- Battery types: LiFePO₄, Sodium-ion, multichemm packs
- Input voltage: 5V DC nominal
- Output voltage: 5V regulated
- Backup runtime: extended compared to capacitor-only models
- Cycle life: 1,000+ cycles for LiFePO₄, depending on chemistry
- Operating temperature: -20°C to +55°C (chemistry-dependent)
- Safe charging and discharge management built in

## Advantages

- Longer runtime for sustained outages
- Supports higher load profiles
- Ideal for applications needing hours of backup rather than seconds or minutes
