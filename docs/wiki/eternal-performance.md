# Stubborn Eternal Performance Data

The **Stubborn Eternal** product line is optimized for instant backup and high endurance.

## Typical Performance

- Supercapacitor bank: 100F to 120F
- Input voltage: 5V DC nominal
- Output voltage: 5V regulated for Raspberry Pi
- Backup response time: < 10 ms
- Cycle life: > 500,000 cycles
- Operating temperature: -40°C to +65°C
- Recommended ambient humidity: 5%–95% non-condensing

## Advantages

- Low maintenance compared to battery-based UPS
- Extremely long operational life
- Reliable performance in extreme environments
