# Stubborn Balance Performance Data

The **Stubborn Balance** line is designed for reliable backup with improved energy density.

## Typical Performance

- Hybrid energy system optimized for Raspberry Pi Zero-class devices
- Input voltage: 5V DC nominal
- Output voltage: 5V regulated
- Backup runtime: longer than standard supercapacitor designs
- Cycle life: 50,000+ cycles
- Operating temperature: -20°C to +60°C
- Fast recovery and stable output under load

## Benefits

- Better runtime than traditional supercapacitor solutions
- Robust operation in mixed indoor/outdoor environments
- Minimal maintenance and chemical aging
