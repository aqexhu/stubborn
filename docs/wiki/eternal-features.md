# Stubborn Eternal Specific Features

The **Stubborn Eternal** model uses high-capacity supercapacitors to provide instant backup and exceptionally long service life.

## Key Features

- Supercapacitor energy storage for maintenance-free operation
- Fast response to input power loss
- High cycle life with minimal degradation
- Wide operating temperature range for industrial environments
- Safe shutdown support for Raspberry Pi and 5V systems
- Compact footprint designed for easy HAT integration

## Use Cases

- Remote IoT gateways
- Industrial automation controllers
- Data logging systems
- Applications where battery maintenance is undesirable
