# Stubborn Balance Specific Features

The **Stubborn Balance** model uses hybrid capacitor technology to balance energy density and long-term reliability.

## Key Features

- Hybrid capacitor energy storage for greater runtime than pure supercapacitors
- Durable construction with high cycle life
- Stable backup support for Raspberry Pi Zero and similar systems
- Low maintenance and safe power-loss detection
- Designed for industrial and remote applications
- Smart shutdown coordination with host systems
