# Stubborn Stamina Specific Features

The **Stubborn Stamina** line uses battery-based energy storage for extended runtime and versatile backup support.

## Key Features

- Multi-chemistry battery support including LiFePO₄ and multichemm battery packs
- Extended runtime for longer outages
- Configurable battery formats and capacities
- Integrated power-loss detection and shutdown sequencing
- Designed for Raspberry Pi and 5V DC systems
- Suitable for industrial, residential, and mobile applications
