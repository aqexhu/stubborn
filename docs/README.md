# Documentation

This directory contains all documentation for the Stubborn Raspberry Pi UPS HAT family.

## Contents

- [`compliance/`](./compliance/) - Regulatory compliance documents (CE, FCC, etc.)
- [`user-manual/`](./user-manual/) - User installation and operation guides
- [`technical-datasheet/`](./technical-datasheet/) - Detailed technical specifications
- [`wiki/`](./wiki/) - Product knowledge base and troubleshooting

## Document Organization

All documents are organized by product model where applicable:
- **Eternal**: Supercapacitor model
- **Balance**: Hybrid capacitor model
- **Stamina**: Multichem battery model

## Contributing to Documentation

When adding new documentation:
1. Use clear, descriptive filenames
2. Include version information
3. Follow the established format
4. Update this README if adding new sections
